SIGNORA MODEL EXPORT - RESULTS

This folder contains the dataset split summary, class distribution,
training history, and test evaluation files when the corresponding
variables were available in the Kaggle notebook.

Important:
- Missing results mean the relevant variables were unavailable.
- Results are calculated from the current notebook variables.
- Keep the test set separate from model training and tuning.
- This experimental model should not be the sole mechanism for
  emergency notifications.
